# Student Grade Calculator

## Description

This JavaScript program calculates the student's final marks by adding bonus marks. It then determines the grade, pass/fail result, remarks, and an extra message.

## Features

- Stores student marks using a variable
- Adds bonus marks using the `+=` assignment operator
- Determines the grade using `if-else`
- Determines Pass or Fail using the ternary operator
- Determines remarks using a `switch` statement
- Uses the logical AND operator (`&&`) for extra messages
- Displays the results using `console.log()`
